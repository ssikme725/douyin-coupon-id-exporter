# 抖店优惠券商品 ID 导出

一个本地 Edge/Chrome 扩展。在已登录的抖店优惠券详情页点击“导出 Excel”，即可把“指定商品（商品券）”里的商品 ID 导出为 `.xlsx`。19 位商品 ID 在表格中保存为文本，不会因 Excel 数字精度限制而改变。

## 安装与使用

见 [使用说明.md](使用说明.md)。

## 工作方式

- 只在用户点击扩展按钮时读取当前标签页。
- 在抖店页面内请求当前优惠券的详情接口，读取 `type_detail` 里的 `product_id`。
- 在浏览器本地生成并下载 Excel；不向其他网站上传商品数据。
- 只申请 `activeTab` 和 `scripting` 权限。

本工具适用于当前抖店页面结构。若抖店更改接口，可能需要更新解析逻辑。

## 开发测试

使用 Node.js 运行 `node test.mjs`。测试使用虚构商品 ID，不包含店铺数据。
