# 抖店优惠券商品 ID 导出

一个本地 Edge/Chrome 扩展。在已登录的抖店优惠券详情页点击“导出 Excel”，即可把“指定商品（商品券）”里的商品 ID 导出为 `.xlsx`。19 位商品 ID 在表格中保存为文本，不会因 Excel 数字精度限制而改变。

## 安装与使用

见 [使用说明.md](使用说明.md)。

## 工作方式

- 只在用户点击扩展按钮时读取当前标签页。
- 在抖店页面内请求当前优惠券的详情接口，读取 `type_detail` 里的 `product_id`。
- 将详情返回数量与页面的“已选数量”核对。数量不一致或详情未带商品时，从页面商品表格第一页逐页补取，直到核对完整；不设 500 条上限。
- 翻页会同时等待页码和商品行更新。漏页、重复页、超时或数量变化会报错，不生成不完整文件。
- 在浏览器本地生成并下载 Excel；不向其他网站上传商品数据。
- 只申请 `activeTab` 和 `scripting` 权限。

本工具适用于当前抖店页面结构。若抖店更改接口，可能需要更新解析逻辑。

## 开发测试

使用 Node.js 运行以下测试。测试使用虚构商品 ID，不包含店铺数据：

```sh
node test.mjs
node page-reader.test.mjs
node popup.test.mjs
```

覆盖 500、501、1000/1001、5000 条商品、长 ID 文本精度、接口截断后的补取、异步分页和失败时禁止下载。

## 1.1.0 修复说明

旧版只读取一次详情接口的 `type_detail`，没有数量核对或补取路径；详情不完整时会漏导，未包含明细时无法导出。Excel 写入本身没有 500 条限制。

新版增加页面分页补取，并兼容结构化明细及 JSON 中未加引号的长整数 ID。分页期间请保持扩展弹窗打开，不要切换优惠券或手动翻页，导出结束时页面会停在最后一页。

验证范围：本地自动测试已覆盖上述场景；当前实店页面停在登录页，尚未对超过 500 个商品的真实优惠券完成验收。平台是否在 500 条处截断或改用其他明细格式，仍需实店响应确认。
